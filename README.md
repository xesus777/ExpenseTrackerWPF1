## Суть проекта
Тестирование авторизации и регистрации пользователей. Для данного проекта были разработаны автоматизированные unit-тесты, проверяющие корректность работы модулей авторизации и регистрации методом "белого ящика".

### Ключевые функции
- Авторизация существующих пользователей
- Регистрация новых пользователей с валидацией данных
- Автоматизированное тестирование позитивных и негативных сценариев
- Проверка всех пользователей из базы данных

---



### Модуль авторизации — LoginPage

**Тестовые сценарии:**
- AuthTest — проверка авторизации существующего пользователя
- AuthTestSuccess — проверка авторизации всех пользователей из БД
- AuthTestFail — проверка негативных сценариев (пустые поля, несуществующий логин, неверный пароль)

### Модуль регистрации — RegisterPage

**Тестовые сценарии:**
- RegisterTestSuccess — позитивный тест регистрации нового пользователя
- RegisterTestFail — негативные тесты (пустые поля, короткий логин, короткий пароль, дубликат пользователя)

## Руководство пользователя

### Страница авторизации — LoginPage

**Порядок действий:**

Заполнить поле «Логин»

Заполнить поле «Пароль»

Нажать кнопку «Войти»

При успешном входе открывается главная страница

При ошибке выводится сообщение «Неверный логин или пароль»

### Страница регистрации — RegisterPage

**Порядок действий:**

Заполнить поле «Логин» (минимум 3 символа)

Заполнить поле «Пароль» (минимум 6 символов)

Подтвердить пароль

Указать Email (необязательно)

Указать Полное имя (необязательно)

Нажать кнопку «Зарегистрироваться»

При успехе — сообщение и переход на страницу входа

При ошибке — красное сообщение с пояснением

## Вероятные трудности
- При отсутствии подключения к базе данных тесты не будут выполняться — необходимо скопировать App.config в тестовые проекты
- Для работы с WPF в тестах требуется STA-поток — используется специальный атрибут STATestMethod
- При добавлении новых пользователей вручную необходимо запускать тесты заново для проверки
